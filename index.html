How It Works

Formulae
  • Exclusive → Gross = Base + (Base × Rate/100)
  • Inclusive → Base = Gross / (1 + Rate/100); GST = Gross − Base
  • CGST & SGST (Intra): Each = GST / 2
  • IGST (Inter): IGST = GST
Tips
  • Use Inclusive when the entered amount already contains tax.
  • Click column headers to cycle focus through inputs (Shift reverses).
